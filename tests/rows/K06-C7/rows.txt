# (a) the install of the tree with LOOP_HOME at the second home: bin, templates, goals, scratch and a config.env whose LOOP_HOME and

# (e) the dispatcher's --dry-run (stand-in claude binary, nothing launched) with LOOP_HOME at the second home prints a goal path under that home
e-dry-run-prints-the-second-home-goal-path :: dispatch :: goal path under the second home :: second
