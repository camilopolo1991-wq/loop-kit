# C1 rows for the writer's shell hook (hooks/writer-git-guard.py).
# Format, one row per line:  id :: mode :: expect :: body
#   mode   nowt = goal from LOOP_GOAL, no writable.txt
#          wt   = goal from LOOP_GOAL, writable.txt lists the tree and the work folder
#          cg   = goal only from the current_goal file, writable.txt present
#          a mode may end in @home: the command runs with its working folder at the test
#          home, which is no listed root. A \n in a body is a line break.
#   expect allow (empty output, exit 0) or deny (a deny decision in the JSON output)
#   body   the command inside the guarded heredoc; the runner wraps it in the wrapper
#          line and the terminator line. Placeholders: {TREE} {HOME} {WORK} {PY} {EV}
#          ({EV} is the fixture goal's evidence folder).
# The first twelve rows are the card's rows; the rest cover the same hook.
