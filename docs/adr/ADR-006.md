# ADR-006: a closed goal is never reopened

## Context

A goal closes with a `GOAL CLOSED` journal line, after its record check passes. Everything a later reader trusts (the report, the audit, the evidence) is a statement about that goal as it stood at the close. A reopened goal would make those statements about a goal that no longer exists.

## Decision

When the leader starts and the journal shows the goal CLOSED, it stops and says so. Later work is a new goal with a new id. The closed goal's report names it as a proposed card.

## Deliberately not

- Not a second `GOAL CLOSED` line for one goal. The audit skill fails a goal where CLOSED appears twice.
- Not an edit of a closed goal's plan, evidence or journal lines to carry new work.
- Not a close line inferred from a bare mention in another entry. The leader reads the line.

## Consequences

- A defect found after a close becomes a card in a later goal, and the earlier audit stands as it was.
- The goal id is an identity: one goal, one directory, one close.
- The record stays consistent with ADR-004. A correction is a new line, in a new goal when the old one is closed.

## Verification

```
bin/loop-journal --read <GOAL-ID> --tail 40
```

Expected: for a closed goal, the last lines hold exactly one `GOAL CLOSED` line. `bin/loop-journal --check <GOAL-ID>` reads the same journal and exits 0 on a goal that closed with every writer PASS preceded by a ROLLBACK line.
